# Práctica - Orientación Laboral (DWES)

Práctica realizada para la asignatura **Desarrollo Web en Entorno Servidor**.

## Descripción del Caso Práctico
Aplicación web diseñada para realizar un test de orientación laboral. El sistema procesa 4 preferencias del usuario y, mediante el uso de estructuras de datos y lógica en servidor, calcula y recomienda un perfil profesional óptimo entre tres categorías: **Desarrollo**, **Soporte** o **Datos**.

## Objetivos y Requisitos Técnicos
1. Creación y gestión de arrays de preguntas.
2. Implementación de funciones lógicas (ej. `sumarPuntos()`).
3. Recorrido de datos y respuestas mediante bucles (ej. `foreach`).
4. Algoritmo de cálculo para determinar la categoría ganadora.
5. Renderizado del resultado y recomendación personalizada al usuario.
